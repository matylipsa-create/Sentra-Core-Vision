# Sentra Core — Motor Paraguas de IA Soberana

> _"El motor primero. Lo demás es consecuencia."_

## Qué es

Sentra Core es un motor paraguas de decisión ética. No es una app. No es una vertical. Es la infraestructura que sirve para construir cualquier aplicación que necesite IA confiable.

## Los 5 principios

1. **Veto humano determinista** — La IA sugiere, el código determina.
2. **Offline-first** — La soberanía no depende de la nube.
3. **Trazabilidad inalterable** — EVOLIS + hash chain ECDSA P-256.
4. **Edge AI** — Inferencia local, sin fuga de datos.
5. **Auto-regulación** — Se adapta al hardware donde corre.
